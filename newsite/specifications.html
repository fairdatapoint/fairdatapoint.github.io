FDP Specifications

The FDP specification defines a **minimal set of HTTP REST API endpoints and RDF vocabularies** that a data provider must implement to expose its metadata in a machine-readable and interoperable way. The specification is based on the **W3C DCAT standard** and extends it with specific classes for data points, catalogues, and datasets.

Key components of the specification:

  • Base URL: The root URL of the FDP instance.
  • API Endpoints: Standardized REST endpoints for retrieving metadata about the data point, catalogues, and individual datasets.
  • RDF Vocabularies: Use of standard RDF vocabularies like DCAT, PROV-O, and schema.org to describe metadata.
  • Content Negotiation: Supports content negotiation to return metadata in different formats (e.g., Turtle, JSON-LD, RDF/XML).

A detailed and versioned specification can be found on our GitHub repository. We encourage community feedback and contributions to evolve the standard.
