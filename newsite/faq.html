Frequently Asked Questions

What is the FAIR Data Point?

The FAIR Data Point (FDP) is a metadata repository that has been designed to follow the FAIR principles. The FDP has a set of specifications that defined how an application needs to behave to be considered a FDP. There are several implementations of these specifications, including a Reference Implementation developed by the FAIR Data Team (also responsible for the definition of the FDP's specifications).

Can I use the FDP for free?

Absolutely. Both the FDP specifications and the Reference Implementations are open source and free to use.
