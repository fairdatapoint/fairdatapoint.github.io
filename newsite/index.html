Making Your Metadata Findable, Accessible, Interoperable, and Reusable

The FAIR Data Point (FDP) is a lightweight but robust metadata repository that enables you to expose the metadata of your digital objects in a machine-readable, FAIR way. FDP makes it easy to create and manage data catalogues, distribute metadata, and ultimately, share your digital objects with the world.

Learn More

Key Features

Flexible metadata schemas

Create metadata about any kind of (digital) object by defining custom metadata schemas based on the W3C's DCAT standard.

Fully HATEOAS API

The best API is no API. The FDP allows smart agents to navigate through its metadata content using the metadata content itselft as guidance (based on W3C's Linked Data Platform).

Machine-readable metadata

Leverages Linked Data principles to create meaningful connections between the metadata and other digital objects, making them more interoperable.

Findability

Makes your metadata and, consequently their described digital objects findable by registering and exposing metadata in a searchable and discoverable way (FDP Index).
